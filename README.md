# 工程项目管理工作台

面向工程项目小组和课程实训的在线协作工具。团队可以在同一工作区拆解任务、跟踪进度、管理风险并验收交付物。

**[打开在线工作台](https://x-j-jun.github.io/engineering-workspace/)**

## 加入工作区

1. 在登录页点击 **注册 → 继续使用 GitHub**，完成授权。首次授权成功后会自动提交加入申请。
2. 由工作区所有者在 **数据管理 → 管理账号权限 → 待审批申请** 中审核并分配角色。
3. 审批通过后，点击 **刷新申请状态** 进入工作台。已有邮箱账号的成员也可直接登录。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 项目总览与待办 | 查看逾期、阻塞、到期风险及待验收事项，按责任人筛选并定位记录 |
| WBS 与进度看板 | 管理任务层级、责任人和交付物，按任务状态查看进度，支持收起看板和按列展开 |
| 风险与问题 | 登记风险，跟踪风险等级、应对措施、责任人和处理期限 |
| 工作包验收 | 为指定工作包启用验收，支持提交、通过、退回和补交 |
| 变更与复盘 | 预演延期影响，比较计划基线，查看项目卡点和跨项目撞期 |
| 数据管理 | 导出项目数据 JSON，预览备份内容并在确认后导入 |

## 成员权限

- **所有者**负责管理成员、审批加入申请和分配角色。
- **项目管理员**负责项目、任务分配、风险和验收条件。
- **提交者**负责分配给自己的工作包，可更新进度与交付物并提交验收。
- **审批者**负责处理待验收工作包，可通过或填写原因退回。
- **只读成员**可查看项目、任务和风险。
